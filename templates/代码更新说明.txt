代码更新包（约 0.2MB）
================

这是给已经装过「学习中心」的人用的，不含 Node 运行时，也不含你的数据。

更新步骤：
1. 先关掉学习中心窗口（右下角托盘/任务管理器里的 node.exe 可以不管，启动.bat 会自动换掉）
2. 把本压缩包里的所有文件解压到原来的「学习中心」文件夹，选「替换目标中的文件」
3. 不要删除 node 文件夹和 data 文件夹
4. 重新双击「启动.bat」

2.5.1 → 2.6.0 是最后一次需要手动覆盖的更新；
从 2.6.0 开始，在页面里点「立即更新」就会只下载变化的文件并自动重启。
2.7.0 的代码包新增了 public/code-lab.js 和 public/code-lab.css；
2.8.0 新增配置记忆接口，server.js 会读写 data/code-lab-profiles.json；
2.9.0 新增 API 平台链接、小白教程和「读取模型」，改动主要在 public/code-lab.js；
覆盖解压后刷新页面，顶部就会出现「💻 代码学习」。

全新的电脑 / 第一次安装，请下载完整的 learning-hub-portable.zip。
