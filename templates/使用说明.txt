学习中心 · 使用说明
====================

1. 双击「启动.bat」
   会打开一个没有地址栏、没有标签页的窗口，那就是学习中心。

2. 第一次打开是空的
   点右上角「＋ 添加课程」，填课程名和你常用的网址（雨课堂、学习通、智慧树、
   中国大学MOOC、B 站……），保存后就会出现在卡片墙上。

3. 顶部还有一排「＋ 自定义网址」
   教务系统、图书馆、作业提交页这种不属于课程的链接可以放这里：
   点「＋ 自定义网址」填名称和地址，之后点一下就能打开。
   鼠标移上去会出现 ×，点它可以删掉。

4. 想加作业 / 截止提醒
   点右上角「＋ 新建任务」，选一个已添加的网址，填上截止时间。
   底部还可以填「指定具体页面」，把这条任务绑到某次作业的详情页。
   顶部切到「任务」视图，会按课程分组、按截止时间从近到远排列。
   每条任务右边有三个按钮：
     ↗  打开它绑定的网址
     ✎  编辑（改名、改时间、改绑定网址）
     ✕  删除

5. 事务：日历版的个人待办
   事务已经并进这个平台：点顶部「📅 事务中心」，或切到「事务中心」视图。
   （网址带 ?view=affairs 也能直接打开，可做桌面快捷方式。）
     · 点月历上的任意格子 → 在这天新建一条事务
     · 填标题、日期、分类、优先级、备注
     · 「相关文件」可以点击选择，也可以把文件直接拖进去；
       一条事务最多 20 个附件，单个文件不超过 20MB
     · 月历上带虚线边框的是课程作业的截止时间，点它能直接改
     · 右侧可以切换「月历 / 列表」，左上角切换月份，「今天」回到当月
     · 分类可以新建；鼠标移到分类上会出现 ✎（改名 / 换颜色）和 ×（删除，
       事务本身不会删，只会变成「未分类」）
   每类事务的颜色显示在月历上的小色块里，高优先级会带一个红色感叹号。

   旧版「我的事务管理」里的数据也能搬过来：
   先在旧页面按 F12 → Application → Local Storage，复制 taskApp2 的值，
   存成一个 .json 文件，再到菜单「⋯ → 导入旧版事务数据」选择它。

6. 自动收集网页上的作业（浏览器扩展，推荐）
   a. Edge 打开 edge://extensions
   b. 打开「开发人员模式」
   c. 点「加载解压缩的扩展」，选择本文件夹里的 extension 目录

   装好后，在任意课程网站都能用（各学校自己的小雅之类也行）。
   认识的平台和 *.*edu.cn 学校网站会直接显示两个按钮；
   其它网站会收成一个小圆点「书」，点一下才展开。

     「收进学习中心」  读取这一页的作业和进度，弹出确认窗口
     「记住此页」      把当前网址存下来，可以存成课程入口，也可以直接绑到某条任务

   在作业页点「记住此页」，会默认选中「某条任务的网址」；
   收集任务时也可以勾选「每条任务都绑定到这个页面」。

   按钮可以按住拖动，位置会记住，不会一直挡着内容。

   ★ 用扩展更新过网址或任务后，回到学习中心点右上角的 ⟳ 刷新，
     才能看到新内容（切回窗口时也会自动刷新一次）。

   注意：本程序要先开着（双击启动.bat）。

7. 数据存在哪
   本文件夹下的 data\db.json（课程、事务、分类、设置）。
   事务的附件在 data\files\ 里，复制备份时两个都要带上；
   或者用菜单里的「导出备份 / 导入备份」，附件会一起打包。

   要更新程序：菜单「⋯ → 检查更新 / 下载新版」会打开固定的发布页，
   不用再问别人要网址；下载新 zip 覆盖解压即可，data 文件夹不会被覆盖。

8. 怎么关掉
   任务管理器里结束 node.exe；或者直接注销 / 重启。

9. 想更像一个桌面程序
   在打开的窗口里：Edge 菜单（⋯）→ 应用 → 将此站点安装为应用。
   之后开始菜单里会有独立图标。

第一次打开被 Windows 拦住？
---------------------------
浏览器下载的压缩包会被标记成"来自其他计算机"，Windows 可能提示
「Windows 已保护你的电脑」或「此文件可能不安全」。

这是 Windows 对未签名程序的统一做法，不代表文件有问题。

解决办法（只需一次）：
1. 右键下载的 zip →「属性」→ 勾选「解除锁定」→ 确定
2. 再解压
3. 运行「启动.bat」时如果还弹提示，点「更多信息」→「仍要运行」

注意
----
· 默认只监听本机（127.0.0.1），同一 WiFi 的其他设备访问不了。
  想让手机也能打开：把「启动.bat」里的 HOST=127.0.0.1 改成
  HOST=0.0.0.0，再在手机浏览器输入 http://电脑的IP:4173
  （改了之后务必在「站点设置」里把密码打开）

· 不需要安装，也不需要联网。只有你自己填进去的那些课程网站需要网络。

· 如果双击没反应，先确认 Edge 或 Chrome 装在默认位置，
  或者手动在浏览器打开 http://127.0.0.1:4173
