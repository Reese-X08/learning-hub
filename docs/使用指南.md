# 学习中心 · 使用手册

> 这是完整的使用说明，面向使用者。项目介绍见 [README](../README.md)。

把雨课堂、小雅、智慧树、中国大学MOOC、B 站、YouTube 这些分散的课程，收进同一个入口。

一个入口，两种用法，共用同一份数据：

| 用法 | 启动 | 特点 |
| --- | --- | --- |
| **浏览器里用** | 双击 `启动.bat`，或访问 `http://localhost:4173` | 手机/平板也能开，密码保护 |
| **装成桌面应用** | 在 Edge 里「安装此站点为应用」 | 独立窗口、开始菜单图标、无地址栏 |

数据都在 `data/db.json`，怎么切换都不会丢。

---

## 一、启动

双击 `启动.bat`。它会：

1. 在后台启动本地服务（不弹窗口）
2. 用 Edge 打开一个**没有地址栏、没有标签页**的独立窗口

终端会打印地址和**首次生成的密码**（后台启动时不显示，密码在第一次 `node server.js` 时打印过，忘了可以重设）：

```
  本机访问   http://localhost:4173
  局域网     http://192.168.1.23:4173
```

改密码（改完要重启服务）：

```bash
node server.js set-password 你的新密码
```

> 不需要密码的话，进「站点设置」把「打开时需要输入密码」取消勾选即可，随时可以再打开。

## 二、装成桌面应用

### 让它出现在开始菜单

用 Edge 打开 `http://127.0.0.1:4173`，然后：

**Edge 菜单（⋯）→ 应用 → 将此站点安装为应用**

之后开始菜单、任务栏里会有一个「学习中心」图标，点开是独立窗口，没有地址栏和标签页，用起来和桌面程序一样。

> 应用清单（`manifest.webmanifest`）、图标和 Service Worker 都已经配好，所以浏览器会把它当成一个可安装的应用，而不是普通网页。

### 这个形态能做到

- 课程卡片墙：进度、状态、备注、分类
- 任务管理：按课程分组、按截止时间从近到远排序、勾选完成
- 每个任务可以绑定自己的网址，点任务直接跳转
- **事务日历**：月历 / 列表两种视图，按分类、优先级管理个人待办，一条事务可以挂多个附件
- 月历上同时叠着课程的截止事项，事务和作业不再分两处看
- 「即将截止」汇总、平台快捷入口
- 手机 / 平板同一 WiFi 访问

### 做不到

| 事情 | 原因 |
| --- | --- |
| 在一个窗口里内嵌雨课堂 / 智慧树 | 平台用 `X-Frame-Options` 禁止被 iframe 嵌入，浏览器层面无解；点「打开」是新开标签页 |

### 把网页上的作业收进来：浏览器扩展

`extension/` 目录是一个 Manifest V3 扩展，装一次即可：

1. Edge 打开 `edge://extensions`
2. 打开「开发人员模式」
3. 点「加载解压缩的扩展」，选择本程序目录下的 `extension` 文件夹

装好后，**任意网站**都会注入收集器（小雅这类各校自建平台也能用）：

| 按钮 | 作用 |
| --- | --- |
| **收进学习中心** | 读出当前页的「作业名 + 截止时间」和「学习进度百分比」，打开确认窗口，按域名自动选中课程，勾选后保存 |
| **记住此页** | 存当前网址：可以设为**课程入口**，也可以直接绑到**某条任务**（作业页默认选任务，还能顺手新建一条任务） |

显示规则：

- 认识的平台（雨课堂、学习通、智慧树、中国大学 MOOC、学堂在线、头歌、PTA、蓝桥、B 站、YouTube）和**所有 `*.edu.cn` 学校域名**（含各校的小雅）→ 直接显示两个按钮
- 其它网站 → 收成一个 34px 的小圆点「书」，点一下才展开，不挡内容
- **按钮可以拖动**：按住拖到不挡内容的位置，松手后位置会记住，下次打开还在那儿
- 拖动超过 5px 就只算移动，不会误触发按钮

> 提取靠的是页面文字规律（`截止 / deadline` + 日期 + `作业/测验/考试`），平台改版可能失效，所以保留了勾选确认这一步。
> 只读当前这一页；作业要点进每门课才展开的，先点进去再按按钮。
> 使用前本程序要开着，否则按钮会提示「学习中心没开着」。

## 三、日常使用

1. 右上角 **＋ 添加课程**：建一个网址入口（课程名、平台、网址）。**不会自动生成任何任务。**
2. 右上角 **＋ 新建任务**：填任务名、截止时间，选一个已添加的网址作为绑定目标；也可以再填一个「具体页面」指向某次作业的详情页。
3. 主区域顶部有 **课程 / 任务 / 事务中心** 三个视图：
   - **课程**：卡片墙，看进度和状态。
   - **任务**：按课程分组，组内按截止时间从近到远排序，最近的课程排在最前；勾选框可以直接标记完成。空日期排在组内最后。
   - **事务中心**：月历 / 列表两种看法的个人待办（见下一节）。顶部也有 **📅 事务中心** 按钮，可直接进入。
   - 每条任务行末尾有 **↗ 打开网址**、**✎ 编辑**、**✕ 删除**。编辑里可以改名、改截止时间、**重新绑定网址**（绑到某次作业的详情页）。
4. 右侧「即将截止」是全局最近的 9 条，**点一下就打开它绑定的网址**（新标签页）。绑定的是任务自己的网址时，标题后面会有个 ↗ 标记。
5. 点卡片任意位置改进度、状态、备注；任务在「截止事项」里编辑，每条都可以单独绑网址。
6. 顶部「平台入口」按平台聚合，点一下直接进该平台。
7. 顶部还有一排 **「＋ 自定义网址」**：可以放教务系统、图书馆、作业提交页这类**不属于课程**的链接。点一下直接打开；鼠标移上去出现 `×` 可以删掉。
8. 菜单 **⋯ → 检查更新 / 下载新版**：直接打开固定的发布页，不用再找人要网址。
9. 快捷键：`/` 搜索，`N` 新建课程，`T` 新建任务，`A` 新建事务，`Esc` 关闭。

### 事务（个人待办 + 日历）

顶部点 **📅 事务中心**（或视图切到 **事务中心**），就是一套日历版的待办管理（从「我的事务管理」整合进来）：

| 功能 | 说明 |
| --- | --- |
| 月历 | 6×7 网格，今天高亮，上/下月补位淡显；点任意格子直接在这天新建事务 |
| 列表 | 按月筛选，按日期升序；勾选圆圈标记完成 |
| 课程截止 | 画在月历上的虚线框条目，点开就是课程的截止事项编辑框；也可以只显示事务或只看课程截止 |
| 分类 | 默认「家庭作业 / 日程安排 / 个人事务」，可新建；鼠标移到分类上出现 `✎`（改名 / 换颜色）和 `×`（删除，事务会变成「未分类」） |
| 优先级 | 低 / 中 / 高，高优先级在月历上带红色 `!` |
| 备注 | 每条事务一段自由文本 |
| 附件 | 点击或拖拽上传，一条事务最多 20 个、单个文件最大 20MB；列表里点文件名直接下载 |
| 统计 | 总事务 / 已完成 / 待办 / 完成度圆环 |
| 搜索 | 在事务视图里，顶部搜索框筛的是事务标题、备注和分类 |

数据跟着 `data/db.json` 走，附件本体存在 `data/files/` 下。导出的备份会把附件一起嵌进 JSON，换电脑导入后附件还能下载。

> 旧版「我的事务管理」的数据（localStorage 里的 `taskApp2`）可以在菜单 **⋯ → 导入旧版事务数据** 里导入：先在旧页面按 F12，把 `taskApp2` 的值复制出来存成 `.json` 文件，再选这个文件即可。导入按「标题 + 日期」去重，可以重复导入不会翻倍。
> 任务和网址的关系：任务属于某门课程，默认用课程的网址；单独填了「具体页面」就优先用那个。
> 小雅平台每所学校私有部署，入口域名不一样，把你的学校地址填进「网址」即可。

## 四、数据与备份

| 文件 | 内容 |
| --- | --- |
| `data/db.json` | 全部课程、事务和设置 |
| `data/db.json.bak` | 上一次保存的自动备份 |
| `data/files/` | 事务附件的本体（文件名是随机编号，原始文件名记在 db.json 里） |
| `data/auth.json` | 密码散列（不存明文） |

菜单里的 **导出备份 / 导入备份** 可以整包迁移（附件的 Base64 内容也会打包进 JSON）。多开浏览器窗口也没关系，数据靠文件修改时间同步。

## 六、安全说明

- 便携版默认只监听本机（`启动.bat` 里 `HOST=127.0.0.1`），同一 WiFi 的设备访问不了。
- 直接 `node server.js` 时默认监听 `0.0.0.0`，靠密码保护；不想暴露就 `HOST=127.0.0.1 node server.js`。
- **密码可以在「站点设置」里关掉**（勾选框「打开时需要输入密码」）。关掉后同一 WiFi 下的设备打开地址会直接进入——只在自己电脑上用可以关；宿舍/家里有别人同一网络时建议保留。
- 密码只存 scrypt 散列，登录失败 5 次锁 60 秒。
- 页面有严格 CSP（`default-src 'self'`、`connect-src 'self' https:`），不加载任何外部脚本；`https:` 只用于可选的更新检查。
- 导入的备份会做字段校验，网址只接受 `http(s)`。
- 事务附件同样需要登录才能下载（`/api/files/…` 走会话校验）；文件名会被清理后再写响应头，存储用的是随机编号，不会因为文件名里的 `../` 写到别处。
- 单个附件限 20MB、一条事务限 20 个，导入/导出走 Base64，所以备份 JSON 会比实际附件大约 1/3。
- `data/` 里有你的课程、事务、附件和密码散列，**不要提交进 git**（`.gitignore` 已排除）。

## 七、常见问题

**启动提示端口被占用**
换个端口：`PORT=5000 node server.js`。

**双击 启动.bat 没有反应**
确认 Edge 或 Chrome 装在默认路径；也可以手动在浏览器打开 `http://127.0.0.1:4173`。

**想彻底关掉后台服务**
任务管理器里结束 `node.exe`，或者注销/重启。
