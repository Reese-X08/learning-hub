学习中心 · 自动更新器
====================

这是什么？
  一个小程序：双击 更新.bat，它会自动检查最新版本、下载约 1MB 的代码包、
  停掉旧服务、替换程序文件、重启并打开学习中心。
  不用再手动解压覆盖，也不会动你的 data 文件夹。

怎么用？
  方法一（推荐）：
    把 更新.bat、updater.ps1 放进「学习中心」文件夹（和 server.js 同一层），
    双击 更新.bat。

  方法二：
    把下载的更新器 zip 解压到任意位置，双击 更新.bat；
    弹出文件夹选择框时，选中「学习中心」文件夹（里面有 server.js）。

它会做什么？
  1. 从 GitHub / jsDelivr 读取最新 version.json
  2. 下载对应的代码更新包，校验版本号
  3. 停掉正在运行的旧服务（只停监听学习中心端口的 node.exe）
  4. 备份旧文件到 data\update-backup\<版本>\，再替换
  5. 启动新服务，轮询 /api/version 确认版本号真的变了
  6. 打开一个新的学习中心窗口；旧窗口可以直接关掉
  7. 如果新版本启动失败，自动恢复上一版并重新启动旧服务

数据安全
  - 不会读写 data\db.json，不会删你的课程 / 事务 / 附件
  - 不会覆盖 node\、data\、local.bat、启动.bat
  - 更新包必须来自 HTTPS，版本号必须和更新源一致

如果失败
  - 看窗口里的红色提示，或 data\updater.log（如果存在）
  - 重新双击 更新.bat 再试一次
  - 还不行就下载完整的 learning-hub-portable.zip 覆盖（data 不会被覆盖）

第一次从 2.5.1 / 2.6.x 升级也能用这个更新器。
